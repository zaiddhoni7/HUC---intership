**GIT :**
      Git is a version control tool used to track changes in code and files


**GITHUB :**
       Github is web based platform that hosts Git Rpositories and helps in storing , sharing and do collabrations on projects online


**Uses of Git & GitHub :**
 
**Uses of GIT :** 
Git is mainly used to manage and protect your code.

**1.Save Code History**
keeps all old versions of your project, so you can go back anytime.

**2.Prevent Code Loss**
If your laptop crashes, you still have previous versions saved

**3.Track Changes**
You can see who changed what and when.

**4.Work Safely**
You can experiment with code without fear of breaking the main project.

**Uses of GitHub :**
GitHub is used to store and share your code online.


**1.Online Backup**
Your project is stored on the internet, safe from device loss.

**2.Team Collaboration**
Many people can work on the same project together.

**3.Show Projects to Companies**
You can show your GitHub profile in resumes and interviews.

**4.Manage Big Projects**
Helps companies manage large software projects easily.

**Basic GIT Operations :**
**GIT Repository** - Project folder on GitHub.

**GIT Commit** -Saving changes  ex:like save button

**GIT Branch**-Separate copy of code for new features.

**GIT Clone**-Download repository to your computer.
Push-Upload code to GitHub.

**Pull**-Download latest code from GitHub.
Pull Request-Request team to merge your code into main project.

**Effectiveness of GitHub in Team Collaboration :**
GitHub makes teamwork easy by sharing code, reviewing changes, and merging work from different people.
